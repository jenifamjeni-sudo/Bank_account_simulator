# **BANK ACCOUNT SIMULATOR**

## About 

The Bank Account Simulator is a simple Python-based project that simulates basic banking operations. It allows users to perform banking activities through a menu-driven interface.

This project is developed to understand and practice fundamental Python programming concepts.

 ## Features
 - Check Account Balance
 - Deposit Money
 - Withdraw Money
 - Display Transaction History
 - Exit the Program

## Technologies Used
Programming Language:   
- Python
Code Editor:
- Visual Studio Code (VS Code)

## Concepts Used
- Functions
- Conditional Statements (if, elif, else)
- Loops (while and for)
- Variables
- Lists
- User Input and Output
